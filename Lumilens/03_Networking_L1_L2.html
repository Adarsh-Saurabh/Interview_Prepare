03: Layer 1 / Layer 2 Networking & Traffic Generators

Focus: Physical Optics (L1), Ethernet Switching & Flow Control (L2), and IXIA/Spirent Traffic Simulation
Relevance: Core subject matter tested across Technical Rounds 1 & 2 for Lumilens

1. The AI Networking Paradigm & Why Lumilens Matters

Traditional cloud networks are designed for North-South traffic (clients hitting web servers).
Modern AI supercomputing clusters (training 100B+ parameter LLMs) are dominated by East-West traffic (>95% of traffic flows horizontally between GPUs):

       [ Spine Switches - 51.2T / 102.4T Optical Fabric ]
          /            |               |            \
     [Leaf 1]       [Leaf 2]       [Leaf 3]       [Leaf 4]
     /      \       /      \       /      \       /      \
  [GPU 1] [GPU 2] [GPU 3] [GPU 4] [GPU 5] [GPU 6] [GPU 7] [GPU 8]
  <==================== AllReduce / All-to-All ====================>

The Cost of a Dropped Packet in AI

In standard TCP web traffic, a dropped packet causes retransmission after a few milliseconds.
In Distributed AI Training (PyTorch / Megatron / DeepSpeed): - GPUs synchronize via collective communication operations (AllReduce, All-to-All). - If one single packet is dropped between GPU 4 and GPU 5, the entire collective synchronization blocks. - Result: Thousands of GPUs stall simultaneously (idle execution), wasting millions of dollars in compute time. - Requirement: AI networks must be strictly lossless and have ultra-low latency jitter. This is achieved via RoCEv2 (RDMA over Converged Ethernet) with hardware Priority Flow Control (PFC) and high-integrity optical links.

2. Layer 1 (Physical Layer & Silicon Photonics)

Key Optical Parameters & Measurement Cheat Sheet

Parameter Definition Typical Values Failure Mode / Impact
Tx Optical Power Total optical power launched by the laser into the fiber. $-1.0\text{ to }+4.0\text{ dBm}$ If too low: signal lost in noise. If too high: saturates or burns receiver photodiode.
Rx Sensitivity Minimum optical power required at receiver to achieve target Pre-FEC BER. $-10.0\text{ to }-14.0\text{ dBm}$ If input power drops below sensitivity: bit errors surge exponentially.
Extinction Ratio (ER) Ratio of optical power in High state ($P_1$) to Low state ($P_0$): $10 \log_{10}(P_1 / P_0)$. $3.5\text{ to }6.0\text{ dB}$ Low ER closes eye height; excessive ER causes laser chirp and pulse dispersion.
Optical Modulation Amplitude (OMA) Difference in optical power: $\text{OMA} = P_1 - P_0$ (linear mW). Measured in $\mu\text{W}$ or $\text{dBm}$ Primary metric for signal power independent of average DC power drift.
Insertion Loss (IL) Optical power lost traversing connectors, switches, or couplers: $P_{\text{in}}(\text{dBm}) - P_{\text{out}}(\text{dBm})$. $< 1.5\text{ dB}$ per connector High loss indicates dirty fiber face, cracked core, or misalignment.
Chromatic Dispersion Different wavelengths travel at different velocities in fiber, spreading pulses over time. $\approx 17\text{ ps}/(\text{nm}\cdot\text{km})$ @ $1550\text{ nm}$ Pulse spreading causes Inter-Symbol Interference (ISI) and closes eye width.

The Optical Eye Diagram

The eye diagram is generated by overlaying repetitive high-speed bits on an optical sampling oscilloscope.

       Amplitude (mW / Volts)
           ^
     P1 ---|----/-----------\----  <- Logical '1' Level
           |   /             \
           |  /   +-------+   \
           | /    |       |    \   <- Eye Opening:
           |<     | EYE   |     >     Height = Vertical Noise Margin
           | \    | OPEN  |    /      Width  = Horizontal Timing Margin
           |  \   +-------+   /
     P0 ---|----\-----------/----  <- Logical '0' Level
           +---------------------> Time (ps / Unit Intervals)
                 <--- EW --->
  1. Eye Height (EH): Vertical margin between $P_1$ and $P_0$. Closed by amplitude noise, attenuation, and insertion loss.
  2. Eye Width (EW): Horizontal opening in Unit Intervals (UI). Closed by jitter and dispersion.
  3. PAM4 Signaling (Pulse Amplitude Modulation 4-Level):
    Modern 100G/200G per lane optical systems do not use NRZ (2 levels). They use PAM4, packing 2 bits per symbol into 4 voltage/optical levels (00, 01, 11, 10).
  4. Creates 3 stacked eye openings in the same vertical amplitude.
  5. Trade-off: Cuts required baud rate in half, but incurs an immediate $-9.5\text{ dB}$ SNR penalty, making robust Forward Error Correction (FEC) mandatory!

Bit Error Rate (BER) & Forward Error Correction (FEC)

$$\text{BER} = \frac{\text{Total Bit Errors}}{\text{Total Bits Transmitted}}$$

  • Pre-FEC BER: Raw bit error rate measured at the physical layer before algorithmic error correction.
  • KP4 FEC (IEEE 802.3ck): Standard Reed-Solomon RS(544, 514) FEC used in 100G/lane Ethernet.
  • Corrects up to 15 symbol errors per 544-symbol codeword.
  • Threshold: Can correct raw Pre-FEC BER up to $2.4 \times 10^{-4}$.
  • Post-FEC BER: Residual bit error rate delivered to the Layer 2 MAC layer.
  • Must be strictly $< 10^{-15}$ (effectively zero bit errors per day at terabit rates).
  • Interview Critical Concept: If Pre-FEC BER rises from $10^{-6}$ to $2.0 \times 10^{-4}$, Layer 2 frame drops remain zero. But the link is on the edge of catastrophic collapse. When Pre-FEC crosses $2.4 \times 10^{-4}$, uncorrectable codewords cause sudden, complete frame loss!

3. Layer 2 (Data Link Layer & Ethernet)

The Complete Ethernet Frame Structure (IEEE 802.3)

+------------------------------------------------------------------------------------+
| Preamble | SFD | Dest MAC | Src MAC | 802.1Q Tag | EtherType | Payload     | FCS   |
| 7 Bytes  | 1B  | 6 Bytes  | 6 Bytes | 4B (Opt)   | 2 Bytes   | 46-1500 B   | 4B    |
+------------------------------------------------------------------------------------+
  \_______________/ \________________________________________________/ \_______/
     PHY Layer                     Protected by CRC-32                  CRC-32
  1. Preamble (7 Bytes: 0xAA $\times$ 7): Alternating 10101010 pattern allowing the receiver PLL to lock clock frequency and phase.
  2. Start of Frame Delimiter (SFD, 1 Byte: 0xAB / 10101011): Signals that the very next bit belongs to the Destination MAC.
  3. MAC Addresses (6 Bytes each): Globally unique 48-bit EUI-48 addresses. First 3 bytes = OUI (vendor), last 3 bytes = NIC serial.
  4. 802.1Q VLAN Tag (4 Bytes):
  5. TPID (2 Bytes, 0x8100): Identifies frame as 802.1Q tagged.
  6. TCI (2 Bytes):
    • PCP (3 bits): Priority Code Point (values 0–7 for QoS). Used directly by PFC!
    • DEI (1 bit): Drop Eligible Indicator.
    • VID (12 bits): VLAN ID (1 to 4094).
  7. EtherType (2 Bytes): Indicates encapsulated Layer 3 protocol (0x0800 IPv4, 0x86DD IPv6, 0x88F7 PTP 1588).
  8. Payload (46 to 1500 Bytes): Minimum 46 bytes required to ensure minimum frame length of 64 bytes (collision detection requirement in CSMA/CD).
  9. FCS / CRC-32 (4 Bytes): Frame Check Sequence. If CRC fails, frame is dropped immediately.

Flow Control: 802.3x Pause vs 802.1Qbb Priority Flow Control (PFC)

[ IEEE 802.3x Standard PAUSE ]
   Switch Buffer Full ====> Sends PAUSE ====> STOPS ALL TRAFFIC ON LINK
   Problem: Head-of-Line Blocking (Low-priority video blocks high-priority control).

[ IEEE 802.1Qbb Priority Flow Control (PFC) ]
   Queue 3 Full (RoCEv2) ====> Sends PFC PAUSE for Priority 3 only ====>
   Queues 0, 1, 2, 4, 5, 6, 7 continue transmitting unblocked!

PFC Hazards & Testing Scenarios

  1. PFC Deadlock: A cyclic dependency where Switch A pauses Switch B, which pauses Switch C, which pauses Switch A. All traffic stops forever.
  2. Pause Storms: A malfunctioning NIC or optical transceiver generates infinite continuous PFC pause frames, choking the fabric. Test automation must inject continuous pauses and verify timeout/watchdog triggers.

4. Traffic Generators (IXIA, Spirent, Scapy)

RFC 2544 Benchmark Suite

In test automation for optical switches and interconnects, RFC 2544 defines the standard test methodologies: 1. Throughput: Maximum rate at which none of the offered frames are dropped. 2. Latency: Time taken for a frame to transit the device (tested at 100%, 75%, 50% load). 3. Frame Loss Rate: Percentage of frames dropped under varying line rates. 4. Back-to-Back Frames: Burst size an optical switch can absorb before dropping packets due to buffer exhaustion.

Hands-on Python Scapy Automation Example

from scapy.all import Ether, IP, UDP, Raw, wrpcap, rdpcap, conf
import time

def generate_optical_test_stream(output_pcap: str, count: int = 1000, jumbo: bool = False):
    """Generates synthetic test frames with embedded sequence numbers."""
    payload_size = 8960 if jumbo else 1400
    packets = []

    for seq_id in range(count):
        # Create Layer 2 Ethernet + Layer 3 IP + Layer 4 UDP
        pkt = (
            Ether(dst="00:11:22:33:44:55", src="00:AA:BB:CC:DD:EE") /
            IP(src="192.168.10.1", dst="192.168.10.2") /
            UDP(sport=50000, dport=50001) /
            Raw(load=f"SEQ:{seq_id:08d}".encode() + b"X" * (payload_size - 12))
        )
        packets.append(pkt)

    wrpcap(output_pcap, packets)
    print(f"Generated {count} frames (Jumbo={jumbo}) to {output_pcap}")

def analyze_captured_pcap(input_pcap: str) -> dict:
    """Parses captured pcap and flags missing or out-of-order sequence IDs."""
    packets = rdpcap(input_pcap)
    received_seqs = []

    for pkt in packets:
        if pkt.haslayer(Raw):
            data = pkt[Raw].load
            if data.startswith(b"SEQ:"):
                seq = int(data[4:12].decode())
                received_seqs.append(seq)

    # Detect drops
    received_seqs.sort()
    dropped = []
    for i in range(len(received_seqs) - 1):
        if received_seqs[i+1] > received_seqs[i] + 1:
            dropped.extend(range(received_seqs[i] + 1, received_seqs[i+1]))

    return {
        "total_captured": len(packets),
        "valid_payload_seqs": len(received_seqs),
        "dropped_count": len(dropped),
        "dropped_seqs": dropped[:10] # Show first 10
    }

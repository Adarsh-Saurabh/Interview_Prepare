### Day 1: Algorithmic Filter & Tree of Space Hackathon
- **Hour 1?3**: Master Functional Graphs in `01_Online_Test_Graphs.html`. Implement Maximum Weight Node, Nearest Meeting Cell, and Largest Sum Cycle in C++ and Python from memory.
- **Hour 4?7**: Master `02_Tree_of_Space_Hackathon.html`. Write the full thread-safe N-ary tree locking implementation. Memorize the canonical top-down lock ordering proof for deadlock freedom.
- **Hour 8**: Benchmark $O(\text{depth})$ and $O(\text{depth} + k)$ operations against naive $O(N)$ approaches.

### Day 2: Systems, Concurrency & Payment LLD
- **Hour 1?3**: Study `03_Concurrency_and_OS.html`. Review MESI cache coherence, false sharing (`alignas(64)`), acquire-release semantics, and double-account transfer deadlock prevention.
- **Hour 4?7**: Study `04_System_Design_LLD_Payment_Gateway.html`. Design a complete Payment Gateway with state machine transitions, dual-layer idempotency (Redis + SQL constraint), and monotonic fencing tokens.
- **Hour 8**: Write out the full Python LLD implementation with OCC versioning.

### Day 3: Resume Defense, Signal Processing Pivot & Outages
- **Hour 1?3**: Study `05_Candidate_Resume_Grilling.html`. Rehearse the 30-second elevator pitches connecting Uplan to Xyne Spaces, and PathMapper to dynamic routing.
- **Hour 4?5**: Practice the M.Tech Signal Processing defense: explaining group delay $\tau_g = \frac{N-1}{2}$ and why Kalman filters prevent thundering-herd routing failures.
- **Hour 6?7**: Study `06_Managerial_and_HR.html`. Walk through the 24/7 payment outage simulation (HDFC crash during Big Billion Days).
- **Hour 8**: Review `07_Quick_Reference.html` for final rapid-fire revision.

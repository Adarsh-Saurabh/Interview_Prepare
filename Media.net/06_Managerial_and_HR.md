## 1. Navigating the JD's AI Tools Directive

The Media.net Job Description contains a very specific clause:
> *"Use AI coding assistants and developer tools responsibly to accelerate development, debugging, testing and documentation—while independently validating the output and maintaining code quality.*
> *Ability to use AI tools as an engineering accelerator—not as a substitute for understanding, reasoning, testing or code ownership.*
> *Note: Interviews and the online assessment evaluate unassisted problem-solving. Your fluency with AI tools is assessed separately, through how you talk about the projects you've built with them."*

### How to Address This in Interviews
* **Never say**: *"AI wrote the code for me,"* or *"I just prompt Gemini/ChatGPT."*
* **Always frame AI as**:
  1. **A Fuzzing & Test-Case Generator**: *"I used LLM APIs to generate adversarial test inputs and verify edge cases in my parser."*
  2. **A Prototyping Accelerator**: *"I drafted the initial boilerplate using AI tools, but profiled every memory allocation, analyzed the generated bytecode, and refactored it for deterministic latency."*
  3. **Strict Code Ownership**: *"Every line of code deployed in my projects was understood, benchmarked, and owned by me. In production, hallucinations cost money and violate SLAs."*

## 2. High-Yield Behavioral Questions (STAR Method)

### Question 1: "Tell me about a time you faced a difficult technical bug under time pressure."
* **Situation**: While building the **Warehouse PathMapper** spatial routing engine, the algorithm crashed with segmentation faults and memory spikes on grids larger than $5,000 \times 5,000$.
* **Task**: I had 48 hours before the client demonstration to scale the routing engine to $10,000 \times 10,000$ grids within a 0.5-second execution budget on a standard laptop CPU.
* **Action**: I profiled the memory allocations using Valgrind and Python's `tracemalloc`. I discovered that dynamic allocation of millions of coordinate tuples was thrashing the garbage collector and causing cache invalidations. I refactored the search graph into flat, contiguous 1D array buffers and implemented a hierarchical topological waypoint graph, reducing node evaluations by 98%.
* **Result**: The engine scaled successfully to $10,000 \times 10,000$ locations, executing in **under 0.48 seconds** with zero memory leaks.

### Question 2: "Tell me about a disagreement you had with a team member and how you resolved it."
* **Situation**: During the **Ziroh Labs Academic Alliance Program**, where I led a team of 5, two developers argued over whether to use an existing deep learning model (ResNet-50) or a lightweight custom unsupervised approach (HOG + Clustering) for video keyframe extraction.
* **Task**: As team lead, I had to ensure project completion ahead of schedule without sacrificing detection accuracy or causing friction.
* **Action**: Rather than deciding subjectively, I instituted an objective benchmark spike. I gave both engineers 24 hours to run their implementations against the same 10-video benchmark dataset, measuring inference speed (FPS), CPU memory usage, and keyframe extraction precision.
* **Result**: The data revealed that the unsupervised HOG approach ran **11 times faster** than ResNet with 96.45% comparable accuracy, making real-time processing viable. Both engineers agreed with the data-driven choice, and we delivered the project ahead of the client deadline.

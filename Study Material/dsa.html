⚡ PRO TIP Grid Problems are Graph Problems Wearing a Matrix Costume!
Whenever an interview presents an $M \times N$ grid with cells (islands, rotting oranges, shortest maze path), treat every cell $(r, c)$ as a graph vertex with up to 4 edges: $(r\pm 1, c)$ and $(r, c\pm 1)$. If edges are unweighted, the shortest path is ALWAYS BFS with a Queue, never DFS or Dijkstra!

# 1. Binary Search on Answer Space (The #1 High-Yield Pattern)

Trigger: The problem asks for the minimum maximum (or maximum minimum), and whether a given candidate value $X$ is feasible is monotonic: if $X$ works, all $Y > X$ work.

📄 Binary Search on Answer Spacecpp
// C++ Binary Search on Answer Template
bool isValid(const vector<int>& weights, int maxCap, int days) {
    int currentDayLoad = 0, requiredDays = 1;
    for (int w : weights) {
        if (currentDayLoad + w > maxCap) {
            requiredDays++;
            currentDayLoad = 0;
        }
        currentDayLoad += w;
    }
    return requiredDays <= days;
}

int shipWithinDays(vector<int>& weights, int days) {
    int low = *max_element(weights.begin(), weights.end());
    int high = accumulate(weights.begin(), weights.end(), 0);
    int optimalAns = high;

    while (low <= high) {
        int mid = low + (high - low) / 2; // Prevents 32-bit overflow!
        if (isValid(weights, mid, days)) {
            optimalAns = mid;      // Mid is feasible, try smaller capacity
            high = mid - 1;
        } else {
            low = mid + 1;         // Mid too small, must expand capacity
        }
    }
    return optimalAns;
}

# 2. Monotonic Stack (Next Greater Element & Daily Temperatures)

📄 Monotonic Stack Templatecpp
// C++ Monotonic Decreasing Stack Template
vector<int> dailyTemperatures(vector<int>& temperatures) {
    int n = temperatures.size();
    vector<int> result(n, 0);
    stack<int> st; // Stores indices

    for (int i = 0; i < n; i++) {
        // While stack not empty and current element is warmer than stack top
        while (!st.empty() && temperatures[i] > temperatures[st.top()]) {
            int prevIdx = st.top();
            st.pop();
            result[prevIdx] = i - prevIdx;
        }
        st.push(i);
    }
    return result;
}

# 3. Disjoint Set Union (DSU with Path Compression & Rank)

📄 DSU with Path Compressioncpp
class DSU {
public:
    vector<int> parent, rank;
    DSU(int n) : parent(n), rank(n, 0) {
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // Path compression: O(alpha(N))
    }

    bool unite(int i, int j) {
        int rootI = find(i), rootJ = find(j);
        if (rootI == rootJ) return false; // Cycle detected!
        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
        else if (rank[rootI] > rank[rootJ]) parent[rootJ] = rootI;
        else { parent[rootJ] = rootI; rank[rootI]++; }
        return true;
    }
};

# 💎 Dynamic Programming: 9 Canonical Shapes

DP Shapes

Campus and tech interviews test the same 9 DP structural shapes repeatedly. Master the transition from 2D table to 1D space optimization.

DP Canonical ShapeState Representation ($dp[i]$ or $dp[i][j]$)Recurrence RelationSpace Optimization Trick
0/1 Knapsack$dp[i][w]$ = max value using items $1..i$ with capacity $w$$dp[i][w] = \max(dp[i-1][w], \text{val}[i] + dp[i-1][w-\text{wt}[i]])$1D array traversed backwards ($W \dots \text{wt}[i]$).
Unbounded Knapsack$dp[w]$ = max value with weight limit $w$$dp[w] = \max(dp[w], \text{val}[i] + dp[w-\text{wt}[i]])$1D array traversed forwards (re-using items).
Longest Common Subseq (LCS)$dp[i][j]$ = LCS length of $s_1[0..i]$ and $s_2[0..j]$If match: $1 + dp[i-1][j-1]$; Else: $\max(dp[i-1][j], dp[i][j-1])$Rolling 2 rows ($dp[2][N]$) or 1D array with prev diagonal.
Longest Increasing Subseq (LIS)$dp[i]$ = length of LIS ending at index $i$$dp[i] = 1 + \max_{j < i, a[j] < a[i]} dp[j]$ ($O(N^2)$)Patience Sorting + Binary Search ($O(N \log N)$).
Grid Minimum Path Sum$dp[r][c]$ = min cost to reach cell $(r, c)$$dp[r][c] = \text{grid}[r][c] + \min(dp[r-1][c], dp[r][c-1])$In-place grid update or 1D array of size $C$.
Coin Change (Min Coins)$dp[a]$ = min coins to make amount $a$$dp[a] = 1 + \min_{c \in \text{coins}} dp[a - c]$1D array initialized to $\infty$, $dp[0] = 0$.
Edit Distance (Levenshtein)$dp[i][j]$ = min edits between $w_1[0..i]$ and $w_2[0..j]$Insert: $dp[i][j-1]$, Delete: $dp[i-1][j]$, Replace: $dp[i-1][j-1]$Rolling 2 rows.
House Robber (Linear)$dp[i]$ = max loot up to house $i$$dp[i] = \max(dp[i-1], \text{nums}[i] + dp[i-2])$2 variables: prev1, prev2 ($O(1)$ space).
Bitmask DP (Travelling Salesman)$dp[mask][u]$ = min cost visiting mask ending at $u$$dp[mask | (1 \ll v)][v] = \min(dp[mask][u] + \text{dist}[u][v])$$O(2^N \cdot N)$ space, for $N \le 20$.

# 0/1 Knapsack: From 2D Matrix to Space-Optimized 1D Array

📄 Space-Optimized 0/1 Knapsackcpp
// Space-Optimized 0/1 Knapsack in O(W) Space
int knapsack(int W, const vector<int>& weights, const vector<int>& values) {
    int n = weights.size();
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++) {
        // CRITICAL: Iterate BACKWARDS from W down to weights[i]
        // This ensures each item is used AT MOST ONCE!
        for (int w = W; w >= weights[i]; w--) {
            dp[w] = max(dp[w], values[i] + dp[w - weights[i]]);
        }
    }
    return dp[W];
}

# 📐 Master Theorem & Amortized Analysis

Analysis
$$T(n) = a T(n/b) + f(n), \quad \text{compare } f(n) \text{ with } n^{\log_b a}$$
🗣️ Spoken Reading: Master Theorem compares non-recursive work f(n) with critical exponent n to the power of log base b of a.
SymbolMeaning & Units
aNumber of subproblems generated in recursion (a >= 1)
bFactor by which problem size is divided (b > 1)
f(n)Work done outside recursive calls (divide and merge steps)
🎯 Practical System Takeaway: Case 1: If f(n) = O(n^(log_b a - epsilon)), leaves dominate -> T(n) = Theta(n^(log_b a)). Case 2: If f(n) = Theta(n^(log_b a)), balanced work -> T(n) = Theta(n^(log_b a) * log n). Case 3: If f(n) = Omega(n^(log_b a + epsilon)), root dominates -> T(n) = Theta(f(n)).
📐 WORKED PROBLEM

Amortized Analysis of std::vector push_back (Dynamic Array Resizing)

Step 1 Identify Doubling Strategy
Vector starts at capacity 1. When full, it allocates an array of size 2C, copies C elements, and inserts the new element.
Step 2 Compute Aggregate Cost over N Insertions
Total normal insertions: N * 1 = N. Copying cost occurs at powers of 2: 1 + 2 + 4 + 8 + ... + N/2 + N = 2N - 1.
Step 3 Derive Amortized Cost per Operation
$$\text{Amortized Cost} = \frac{\text{Total Cost}}{N} = \frac{N + (2N - 1)}{N} = \frac{3N - 1}{N} \approx 3 = O(1)$$
👁️ Click to Reveal Final Verification & Answer
Even though an individual push_back takes O(N) when resizing, the amortized cost per operation is provably O(1)!

# 🌐 Graphs, Strings & Greedy Validity

Advanced CS

# Why Dijkstra's Algorithm Fails on Negative Edges

Dijkstra is a greedy algorithm that relies on the invariant that once a vertex's distance is extracted from the PriorityQueue, its shortest path is permanently settled. If an edge with a negative weight exists later in the graph, it can retroactively shorten the distance of an already-settled vertex, violating the invariant! Use Bellman-Ford or SPFA instead.

# Greedy Validity & The Exchange Argument

A greedy choice is only valid if taking the local optimum never prevents reaching the global optimum. For instance, Coin Change is greedy for canonical US denominations ((1, 5, 10, 25)), but fails completely for denominations (1, 3, 4) to make target 6: Greedy picks 4 + 1 + 1 (3 coins), whereas the global optimum is 3 + 3 (2 coins)!

# ⚠️ High-Frequency Traps & Proofs

Interview Traps
⚠️ INTERVIEW TRAP Trap #1: Integer Overflow in Binary Search
Writing int mid = (low + high) / 2; leads to signed 32-bit integer overflow when low + high > 2,147,483,647, causing a negative index and immediate segfault. Always write int mid = low + (high - low) / 2;.
⚡ PRO TIP Trap #2: Why Building a Binary Heap is O(N) and NOT O(N log N)
Inserting $N$ elements into an empty heap sequentially takes $N \times O(\log N) = O(N \log N)$. However, bottom-up std::make_heap() takes $O(N)$ because the majority of nodes reside at the bottom: $N/2$ leaves require 0 swaps, $N/4$ nodes require at most 1 swap. The sum evaluates to $\sum_{{h=0}}^{{\log N}} \frac{{N}}{{2^{{h+1}}}} \times h = N \times 1 = O(N)$.
∑ MATHEMATICAL GROUNDING Trap #3: Floyd's Tortoise and Hare Algebraic Proof
When Slow and Fast meet in a linked list loop, resetting Slow to the head and advancing both by 1 step guarantees they meet at the cycle entrance. Proof: $2(F + a) = F + a + nC \implies F = nC - a$. Walking $F$ steps from head and $F$ steps from the meeting point lands both pointers exactly at the entrance.

# 🎯 32 Top Tech Interview Q&As

Why does (low + high) / 2 overflow and what is the fix?
EasyBinary SearchGoogleApple
If low + high exceeds 2^31 - 1, it overflows to a negative integer in signed 32-bit systems, resulting in an out-of-bounds segfault. The fix is: mid = low + (high - low) / 2.

Prove that building a Binary Heap takes O(N) time instead of O(N log N).
MediumHeapsMathMicrosoftAmazon
Bottom-up heap construction (make_heap) runs heapify starting from non-leaf nodes. Since N/2 nodes are at height 0 (0 swaps), N/4 at height 1 (1 swap), N/8 at height 2 (2 swaps), the total swaps sum to N * sum(h / 2^(h+1)) = N * 1 = O(N).

How do you detect cycles in a Directed vs Undirected graph?
MediumGraphsMedia.netCred
Undirected: BFS/DFS (if neighbor is visited and not parent) or Disjoint Set Union (DSU). Directed: DSU does NOT work! Must use 3-Color DFS (recursion stack back-edge) or Kahn's Algorithm (Topological Sort BFS: if processed nodes < V, cycle exists).

EasyHashingAppleQualcomm
Uses separate chaining (array of buckets pointing to linked lists). Average O(1), worst-case O(N) when all keys hash to the same bucket. In Java 8+, buckets with >= 8 elements convert to Red-Black Trees for O(log N) worst-case.

Why does Dijkstra's algorithm fail on graphs with negative edge weights?
MediumGraphsCiscoNokia
Dijkstra is greedy: it marks a vertex permanently finalized once extracted from the priority queue, assuming all future paths will be longer. A negative edge can make a subsequent path shorter, violating this invariant.

When is a Greedy algorithm provably optimal? Give a case where it fails.
HardGreedyJuspayMedia.net
Optimal when it possesses the Greedy Choice Property and Optimal Substructure (verified via the exchange argument). Fails for Coin Change with non-canonical denominations like {1, 3, 4} for target 6 (greedy picks 4+1+1 = 3 coins; optimal is 3+3 = 2 coins).

How do you find the Longest Increasing Subsequence (LIS) in O(N log N)?
HardDPGoogleMeta
Using Patience Sorting and binary search (std::lower_bound). Maintain a tails array where tails[len] stores the smallest tail of all increasing subsequences of length len + 1.

What is Monotonic Stack and what class of problems does it solve in O(N)?
MediumStackSwiggyCred
A stack maintaining strictly increasing or decreasing order. Solves range-bound queries like Next Greater Element, Daily Temperatures, and Largest Rectangle in Histogram in linear time.

Explain the difference between Memoization (Top-Down) and Tabulation (Bottom-Up).
EasyDPAmazonFlipkart
Memoization uses recursion with a lookup cache, evaluating only reachable subproblems. Tabulation iteratively fills an array from base cases up, eliminating recursion stack overhead and enabling space optimization.

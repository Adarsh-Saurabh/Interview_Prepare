# ⚡ 15-Min Sprint: Probability & Linearity of Expectation

Probability
🗣️ 15-SECOND INTERVIEW ANSWER

"Linearity of Expectation is the single most powerful tool in quant interviews: E[X + Y] = E[X] + E[Y] holds ALWAYS, regardless of whether random variables X and Y are completely dependent or independent."

Aptitude and probability rounds gate Indian campus placement drives (Pace ₹41L HFT, Qualcomm, Apple, TI). Mastering indicator variables trivializes problems that are otherwise mathematically intractable.

$$\mathbb{E}[X] = \sum_{i=1}^n \mathbb{E}[I_i] = \sum_{i=1}^n P(A_i)$$
🗣️ Spoken Reading: Expected value of sum of indicator variables equals sum of individual event probabilities.
SymbolMeaning & Units
I_iIndicator variable: equals 1 if event A_i occurs, else 0
P(A_i)Probability of event A_i occurring
E[I_i]Expected value of an indicator equals its probability: E[I_i] = P(A_i)
🎯 Practical System Takeaway: Allows computing expected matches, fixed points in permutations, or collisions without computing joint probability distributions!
📐 WORKED PROBLEM

Expected Number of Fixed Points in a Random Permutation of N Elements

Step 1 Define Indicator Variables
Let $I_i = 1$ if element $i$ lands in position $i$ (a fixed point), and $0$ otherwise.
Step 2 Compute Single Probability
For any individual position $i$, each of the $N$ elements is equally likely to land there: $P(I_i = 1) = \frac{1}{N}$.
Step 3 Apply Linearity of Expectation
$$\mathbb{E}[\text{Total Fixed Points}] = \sum_{i=1}^N \mathbb{E}[I_i] = \sum_{i=1}^N \frac{1}{N} = N \times \frac{1}{N} = 1$$
👁️ Click to Reveal Final Verification & Answer
The expected number of fixed points in ANY random permutation of size N is exactly 1, whether N = 10 or N = 1,000,000,000!

# 25 Horses, 5 Tracks, No Timer (Find Top 3)

Solution: 7 Races.

  • Races 1-5: Race 5 groups of 5 horses. Identify winner of each group ($A_1, B_1, C_1, D_1, E_1$).
  • Race 6: Race the 5 group winners against each other. Suppose order is $A_1 > B_1 > C_1 > D_1 > E_1$. $A_1$ is guaranteed fastest overall! Eliminate $D$ and $E$ groups entirely.
  • Race 7: Top 2 and 3 can only come from: $A_2, A_3, B_1, B_2, C_1$ (5 horses). Race them together to determine 2nd and 3rd place!

# 💻 Probabilistic Coding: Reservoir & Fisher-Yates

Algorithms
📄 Reservoir Sampling (O(1) Space Streaming)python
# Reservoir Sampling: Select 1 item uniformly from an unbounded stream
import random

def reservoir_sample_stream(stream):
    candidate = None
    count = 0
    
    for item in stream:
        count += 1
        # Pick current item with probability 1 / count
        if random.random() < (1.0 / count):
            candidate = item
            
    # Mathematically guarantees every item has exact probability 1 / N of being chosen!
    return candidate
❌ ANTI-PATTERN vs ✅ PRODUCTION FIX

Uniform In-Place Array Shuffling

❌ Broken / Buggy / Anti-Pattern
# BROKEN Naive Shuffle (NOT UNIFORM)
def naive_shuffle(arr):
    n = len(arr)
    for i in range(n):
        # Swap with ANY index 0..n-1
        j = random.randint(0, n - 1)
        arr[i], arr[j] = arr[j], arr[i]
# Produces n^n outcomes, which is NOT divisible by n!
# Results in severe statistical bias!
✅ Safe / Correct / Idiomatic Fix
# CORRECT Fisher-Yates Shuffle (PROVABLY UNIFORM)
def fisher_yates_shuffle(arr):
    n = len(arr)
    for i in range(n - 1, 0, -1):
        # Swap with index 0..i ONLY
        j = random.randint(0, i)
        arr[i], arr[j] = arr[j], arr[i]
# Produces exact n! outcomes, each with probability 1 / n!
⚠️ Failure Mode & Root Cause: Naive swapping generates n^n permutations. Because n^n is never divisible by n! for n > 2, some permutations occur more frequently than others, failing uniformity tests in gaming and randomized trials.

Why is the expected number of coin flips to get HH equal to 6, while HT takes 4?
HardProbabilityPace (₹41L)OpenAI
Let E[HH] be expected flips. If you get H then T, you lose all progress and restart from 0. For HT, if you get H then H, you remain in the 'have 1 Head' state and only need T on the next flip. Thus HT has faster expected recovery.

Explain the Monty Hall problem. Why is switching doors strictly better?
MediumProbabilityCampus Drives
Your initial pick has a 1/3 chance of having the car and 2/3 chance of having a goat. Because the host MUST reveal a goat behind one of the other doors, switching transfers the 2/3 probability of the other two doors to the single unchosen door.

HardBrainteasersPaceDE Shaw
3 weighings. Each weighing has 3 outcomes (Left, Right, Equal), yielding 3^3 = 27 information states. 12 coins have 24 possible states (each coin can be heavy or light). Since 24 <= 27, 3 weighings are sufficient.

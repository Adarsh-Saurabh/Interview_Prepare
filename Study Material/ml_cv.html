Machine Learning & Vision

1. Machine Learning Evaluation Metrics Cheat Sheet

Metric Mathematical Formula When to Prioritize in Production
Precision $$ rac{TP}{TP + FP}$$ When False Positives are expensive (e.g. Spam detection, YouTube content takedown, fraud alerts).
Recall (Sensitivity) $$ rac{TP}{TP + FN}$$ When False Negatives are fatal (e.g. Cancer detection, autonomous vehicle pedestrian detection!).
F1-Score $$2 imes rac{ ext{Precision} imes ext{Recall}}{ ext{Precision} + ext{Recall}}$$ Harmonic mean; optimal for evaluating models on imbalanced classification datasets.
ROC-AUC Area under True Positive Rate vs False Positive Rate curve. Measures model classification ranking ability across all decision thresholds.
mAP (Mean Average Precision) $$ rac{1}{|C|} \sum_{c \in C} AP_c ext{ at IoU} \ge 0.50$$ Standard benchmark for Object Detection (YOLO, Faster R-CNN) evaluating bounding box location + class accuracy.

2. Optimizers & Loss Functions Matrix

Optimizer / Loss Core Mathematical Idea Key Strengths & Pitfalls
Adam (Adaptive Moment Estimation) Maintains exponential moving averages of both past gradients ($m_t$, first moment) AND squared gradients ($v_t$, second moment). Fast initial convergence across sparse gradients; can struggle with generalization compared to tuned SGD.
AdamW (Decoupled Weight Decay) Decouples $L_2$ regularization weight decay from gradient moment updates ($w_{t+1} = w_t - \gamma \lambda w_t - \gamma rac{m_t}{\sqrt{v_t} + \epsilon}$). Industry Gold Standard for training modern Vision Transformers and LLMs!
Cross-Entropy Loss $$L = - \sum y_i \log(\hat{y}_i)$$ Penalizes confident wrong classifications logarithmically; standard for multi-class classification.
Focal Loss $$FL(p_t) = -lpha_t (1 - p_t)^\gamma \log(p_t)$$ Dynamically scales loss down for well-classified easy background examples; dominates extreme class imbalance in object detection (RetinaNet).

1. Convolution Spatial Dimension & Receptive Field Formulas

Given an input feature map of size $I$, kernel size $K$, padding $P$, and stride $S$, the output dimension $O$ is:

$$O = \left\lfloor rac{I - K + 2P}{S} ight floor + 1$$
💡 Why Stack Two 3x3 Conv Layers Instead of One 5x5 Conv Layer? (VGG Principle)
  1. Identical Effective Receptive Field: Two stacked $3 imes 3$ convolutions cover $3 + (3 - 1) = 5 imes 5$ spatial area!
  2. 28% Fewer Parameters: For $C$ channels, a $5 imes 5$ conv requires $5 imes 5 imes C^2 = 25C^2$ weights. Two $3 imes 3$ layers require $2 imes (3 imes 3 imes C^2) = \mathbf{18C^2}$ weights!
  3. Greater Non-Linear Representational Power: Stacking two layers introduces two ReLU activation functions instead of one.

2. Batch Normalization vs Layer Normalization

Feature Batch Normalization (BatchNorm) Layer Normalization (LayerNorm)
Dimension of Normalization Computes mean $\mu$ and variance $\sigma^2$ across the Batch dimension $N$ for each channel independently: $(N, H, W)$. Computes mean $\mu$ and variance $\sigma^2$ across the Channel/Feature dimensions $(C, H, W)$ for each individual sample in the batch.
Batch Size Sensitivity Extremely sensitive: Fails when batch size is small ($N < 8$); batch statistics become noisy and drift. Completely invariant to batch size; behaves identically whether batch size is 1 or 256!
Training vs Inference Tracks exponential running mean and running variance during training; freezes them at test time (can cause train-test mismatch). Identical computation at both training and inference time!
Domain / Model Usage Standard in Convolutional Networks (ResNet, ConvNeXt). Standard in Transformers, LLMs, and Vision Transformers (ViT).

⚠️ High-Frequency ML & CV Traps

Recruiter Traps
Trap #1: Why ROC-AUC Misleads on Highly Imbalanced Data

The Trap: In fraud detection (99.9% legitimate, 0.1% fraud), a model achieves an impressive 0.98 ROC-AUC score, yet flags thousands of innocent transactions!

Why: ROC curves plot True Positive Rate ($TP / (TP+FN)$) against False Positive Rate ($FP / (FP+TN)$). Because the negative class is massive ($TN = 1,000,000$), a surge in false positives ($FP = 1,000$) causes negligible impact on FPR ($1000 / 1001000 pprox 0.00099$). Always use PR-AUC (Precision-Recall Curve), which does not include $TN$ and exposes high false-positive rates immediately!

💡 How ResNet Skip Connections Eliminate Vanishing Gradients

In a standard neural network, gradients pass through successive weight matrices during backpropagation via the chain rule: $ rac{\partial L}{\partial x} = rac{\partial L}{\partial y} \cdot W$. If $|W| < 1$, repeated multiplication causes gradients to exponentially decay to zero as depth exceeds 20 layers.

In ResNet with residual skip connections $y = F(x) + x$, the gradient becomes:

$$ rac{\partial y}{\partial x} = rac{\partial F(x)}{\partial x} + \mathbf{1}$$

Because of the $+1$ additive identity term, the error gradient can flow directly backward through the skip connection to shallow layers with zero signal attenuation, enabling networks to scale to 152+ layers successfully!

🎯 Interview Q&A Flashcards (Self-Assessment)

5 Questions
Q1: How does Non-Maximum Suppression (NMS) work in Object Detection?
Object detectors generate multiple redundant overlapping bounding boxes for the same object.
NMS Algorithm:
  1. Sort all predicted bounding boxes by their confidence scores.
  2. Select the box with highest score, add it to final detections.
  3. Calculate Intersection over Union (IoU) between this selected box and all remaining candidate boxes.
  4. Discard any candidate box with $ ext{IoU} > ext{Threshold}$ (typically 0.50).
  5. Repeat until no candidate boxes remain.
Q2: What is the 5-Stage Canny Edge Detection Algorithm?
  1. Gaussian Blur: Smooths image to suppress high-frequency noise.
  2. Gradient Intensity & Direction: Convolves with Sobel kernels to compute magnitude $G = \sqrt{G_x^2 + G_y^2}$ and angle $ heta = rctan(G_y / G_x)$.
  3. Non-Maximum Suppression (Thinning): Suppresses pixels that are not local maxima along the gradient direction, thinning edges to 1-pixel width.
  4. Double Thresholding: Classifies edge pixels into Strong, Weak, or Non-edge based on High and Low thresholds ($T_{high}, T_{low}$).
  5. Hysteresis Edge Tracking: Preserves weak edge pixels only if they are physically connected to a strong edge pixel.
Q3: What causes Data Leakage in Machine Learning pipelines?
Data leakage occurs when information from outside the training dataset is inadvertently used to create the model.
• Classic Mistake: Performing scaling (StandardScaler.fit_transform), target encoding, or outlier removal on the entire dataset before splitting into train/test! The mean and variance of the test set leak into the training process.
• Prevention: Always split data first, or wrap preprocessing and modeling inside an end-to-end Pipeline.
Q4: How does HOG achieve illumination invariance?
In HOG, gradients capture edge transitions rather than raw pixel intensities (a shift in overall lighting adds a constant value that cancels out during differentiation: $ rac{\partial (I + c)}{\partial x} = rac{\partial I}{\partial x}$).
Furthermore, HOG groups cells into overlapping $16 imes 16$ blocks and performs L2-Hys Normalization ($v o rac{v}{\sqrt{\|v\|_2^2 + \epsilon^2}}$), making the descriptor vector completely invariant to illumination scaling and contrast changes!
Q5: What is the difference between Transposed Convolution and Bilinear Upsampling?
• Transposed Convolution (Deconvolution): Learnable upsampling layer with trainable kernel weights. Can learn complex non-linear spatial reconstructions, but prone to "checkerboard artifacts" if kernel size is not divisible by stride.
• Bilinear / Nearest-Neighbor Upsampling: Fixed deterministic mathematical interpolation with zero learnable weights. Cheaper, faster, and avoids checkerboard artifacts; usually followed by a standard $1 imes 1$ conv.

# ⚡ 15-Min Sprint: Transformer Anatomy & Attention

Core Architecture
🗣️ 15-SECOND INTERVIEW ANSWER

"Transformer generation is memory-bandwidth bound, not compute-bound: decoding one token requires loading all weights and the entire KV cache from GPU VRAM into SRAM, which is why PagedAttention and GQA define modern inference."

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$
🗣️ Spoken Reading: Attention equals softmax of query times key transpose divided by square root of key dimension, multiplied by values.
SymbolMeaning & Units

KKeys matrix of shape [Batch, Sequence_Len, d_k]
VValues matrix of shape [Batch, Sequence_Len, d_v]
d_kHidden dimension per attention head (typically 64 or 128)
🎯 Practical System Takeaway: Dividing by sqrt(d_k) prevents dot products from growing excessively large for large dimensions. Without scaling, large dot products push the softmax function into regions with near-zero gradients (saturation), freezing backpropagation.

# 🧠 Attention Matrix: MHA vs MQA vs GQA

Memory Optimization

In auto-regressive text generation, previous tokens' Keys and Values are cached in GPU memory (the KV Cache) so they don't need recomputing at each decode step. MHA stores full KV heads for every query head, blowing past GPU VRAM limits at 32k context.

🔍 Attention Head Topologies: MHA (Full), GQA (Grouped-Query), MQA (Multi-Query)
Attention VariantQuery HeadsKey/Value HeadsKV Cache Size Relative to MHAProduction Adoption
Multi-Head Attention (MHA)$H$$H$$1.0\times$ (Baseline)GPT-3, Original Transformer, ViT.
Grouped-Query Attention (GQA)$H$$G = H / 4$ or $H / 8$$0.25\times$ (75% savings)Llama 2/3 (70B), Mistral 7B, Gemma.
Multi-Query Attention (MQA)$H$$1$$1 / H \approx 0.03\times$ (97% savings)PaLM, StarCoder (slight perplexity degradation).

# 📐 KV Cache Memory Scaling & Inference Latency

Capacity Math
$$\text{Memory}_{\text{KV}} = 2 \times n_{\text{layers}} \times n_{\text{KV\_heads}} \times d_{\text{head}} \times \text{seq\_len} \times \text{batch} \times \text{bytes\_per\_elem}$$
🗣️ Spoken Reading: KV Cache memory equals two times layers times KV heads times head dimension times sequence length times batch size times precision bytes.
SymbolMeaning & Units
2Factor of 2 accounts for both Keys and Values
n_layersTotal transformer layers in model (e.g. 80 layers in 70B)
n_KV_headsNumber of distinct Key-Value heads (8 in GQA)
seq_lenContext length in tokens (e.g. 8,192 tokens)
bytes_per_elem2 bytes for FP16 / BF16, 1 byte for FP8
🎯 Practical System Takeaway: KV Cache scales linearly with sequence length and batch size. For a 70B model with 8K context and batch 16, MHA requires 160 GB VRAM (exceeding an 80GB A100 GPU), while GQA drops this to ~20 GB!
📐 WORKED PROBLEM

Calculating KV Cache Memory for Llama 3 70B (8K Context, Batch 16 in FP16)

Step 1 Identify Model Parameters
Layers $L = 80$, KV heads $n_{kv} = 8$ (GQA), Head dimension $d = 128$, Seq length $S = 8,192$, Batch $B = 16$, FP16 precision = 2 bytes.
Step 2 Apply Formula
$$\text{Memory} = 2 \times 80 \times 8 \times 128 \times 8,192 \times 16 \times 2$$
Step 3 Calculate Total Bytes
$$\text{Memory} = 42,949,672,960\text{ bytes} \approx 40.0\text{ GB}$$

Under GQA, the KV cache requires exactly 40.0 GB of VRAM. If this model used MHA (64 KV heads), it would require 320 GB of VRAM, making inference impossible on a single node without tensor parallelism!

# 🎯 Post-Training: SFT, DPO, GRPO & RLVR

Post-Training
⚖️ Decision Matrix: Post-Training Alignment Algorithms
Option / PatternPrime Use-Cases (Best Choice)Anti-Patterns / Failure Points
Supervised Fine-Tuning (SFT) USE WHEN: Teaching format adherence, system prompt compliance, tool schemas, and domain terminology. AVOID WHEN: Alleviating hallucinations or teaching reasoning (SFT causes model to overfit to output distribution).
Direct Preference Optimization (DPO) USE WHEN: General preference alignment without running a separate reward model or RL critic network. AVOID WHEN: Mathematical and logical verification tasks (DPO can cause length bias and verbosity hacking).
Group Relative Policy Optimization (GRPO) USE WHEN: Verifiable reasoning domains (Math, Coding, Competitive Logic). Drops the critic network entirely by group-normalizing rewards. AVOID WHEN: Subjective creative writing where rule-based ground-truth verification is impossible.
Reinforcement Learning with Verifiable Rewards (RLVR) USE WHEN: Theorem proving and programming benchmarks where an automated compiler/test suite produces binary 0/1 correctness. AVOID WHEN: Ambiguous conversational interactions with human nuance.
🤖 MODERN AI NUANCE Why GRPO (DeepSeekMath / R1) Drops the Critic Network
In standard PPO, a second 'Critic' neural network (value model) matching the policy model's size must be kept in VRAM to estimate state value baseline $V(s)$. GRPO samples a group of $G$ candidate outputs for the same prompt, computes their task reward, and normalizes advantage across the group: $A_i = \frac{R_i - \text{mean}(R)}{\text{std}(R)}$. This slashes training VRAM by ~50% and eliminates unstable value-function training!

# Low-Rank Adaptation (LoRA) Architecture

LoRA freezes pretrained weight matrix $W_0 \in \mathbb{R}^{d \times k}$ and injects low-rank trainable matrices: $W = W_0 + \frac{\alpha}{r} (B \cdot A)$, where $A \sim \mathcal{N}(0, \sigma^2) \in \mathbb{R}^{r \times k}$ and $B = 0 \in \mathbb{R}^{d \times r}$ with rank $r \ll d$.

📄 PyTorch Scaled Dot-Product Attentionpython
# Scaled Dot-Product Attention in Pure PyTorch with Causal Mask
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    # Q, K, V shape: [batch, heads, seq_len, head_dim]
    d_k = Q.size(-1)
    
    # Compute attention scores
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    
    if mask is not None:
        # Apply -inf mask before softmax to prevent seeing future tokens
        scores = scores.masked_fill(mask == 0, float('-inf'))
        
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights

# ∑ Information Theory Corner (Candidate Edge)

M.Tech Differentiator

OpenAI coding and deep-dive technical rounds frequently test information theory fundamentals (implementing continuous KL divergence, cross-entropy minimization, perplexity bounds). This directly maps to your M.Tech Signal Processing coursework.

ConceptMathematical FormulaEngineering Interpretation in LLMs
Entropy $H(X)$$-\sum p(x) \log_2 p(x)$Average information / uncertainty in the token distribution. A uniform distribution over vocabulary $V$ has $H = \log_2 |V|$.
Cross-Entropy$-\sum y_i \log \hat{y}_i$Training loss for predicting the next token. Equal to expected negative log-likelihood of ground-truth token.
KL Divergence $D_{\text{KL}}(P \parallel Q)$$\sum P(x) \log \frac{P(x)}{Q(x)}$Relative entropy. Measures penalty in RLHF/DPO to prevent policy model $\pi_\theta$ from drifting away from base model $\pi_{\text{ref}}$.
Perplexity (PPL)$\exp(\text{Cross-EntropyLoss})$Geometric average branching factor. PPL of 10 means the model is as confused as picking among 10 equally likely words.
📄 Continuous Empirical KL Divergence (OpenAI Drill)python
import numpy as np

def kl_divergence_continuous(p_samples, q_samples, bins=100):
    # Verbatim OpenAI drill: Compute KL divergence between two continuous empirical distributions
    min_val = min(np.min(p_samples), np.min(q_samples))
    max_val = max(np.max(p_samples), np.max(q_samples))
    
    p_hist, edges = np.histogram(p_samples, bins=bins, range=(min_val, max_val), density=True)
    q_hist, _ = np.histogram(q_samples, bins=bins, range=(min_val, max_val), density=True)
    
    # Epsilon smoothing to prevent division by zero or log(0)
    eps = 1e-12
    p_prob = (p_hist + eps) / np.sum(p_hist + eps)
    q_prob = (q_hist + eps) / np.sum(q_hist + eps)
    
    return np.sum(p_prob * np.log(p_prob / q_prob))

Why do we divide attention scores by sqrt(d_k)?
EasyTransformerAnthropicOpenAI
For large d_k, dot products grow large in magnitude, pushing the softmax function into regions with near-zero gradients (saturation), resulting in vanishing gradients during training.

What is the KV Cache and why does it matter for autoregressive generation?
EasyInferenceMetaApple
During token generation, tokens attend to all previous tokens. Caching previous Keys and Values prevents recomputing past activations, reducing per-token generation complexity from O(N^2) to O(N).

Compare MHA, MQA, and GQA. Why did Llama 3 adopt GQA?
MediumArchitectureMetaMistral
MHA has 1 KV head per Query head (highest RAM). MQA has 1 KV head for all Query heads (lowest RAM, quality degradation). GQA groups Query heads to share KV heads, slashing KV cache memory by 75% with minimal quality loss.

What is RoPE (Rotary Position Embedding) and why is it preferred over learned embeddings?
MediumEmbeddingsAnthropicGoogle
RoPE multiplies 2D chunks of Query/Key vectors by a 2D rotation matrix. It preserves relative token distance naturally via dot product trigonometry, has zero trainable parameters, and enables context extrapolation.

Why does GRPO drop the critic network, and how does it estimate advantage?
HardAlignmentRLDeepSeekOpenAI
GRPO generates a group of G candidate answers for a single prompt, scores them, and computes advantage by normalizing rewards across the group: A_i = (R_i - mean(R)) / std(R). This eliminates the critic model, saving ~50% VRAM.

What is LoRA and how does it achieve parameter-efficient fine-tuning?
MediumPEFTApple AIMeta
LoRA freezes base weights W0 and decomposes weight updates into two low-rank matrices: delta_W = (alpha / r) * B * A, where r << d. This reduces trainable parameters by >99% and merges into W0 at inference with zero latency penalty.

What is PagedAttention and what problem does it solve in vLLM?
HardServingvLLMAnyscale
In standard inference, KV cache requires contiguous virtual memory, causing 60-80% memory fragmentation and memory waste. PagedAttention divides the KV cache into non-contiguous fixed-size memory blocks (virtual memory paging), boosting serving throughput by 2x-4x.

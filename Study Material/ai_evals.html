# ⚡ 15-Min Sprint: Evaluation Hierarchy & Graders

Core Philosophy
🗣️ 15-SECOND INTERVIEW ANSWER

"Push as much evaluation as humanly possible into deterministic code graders (JSON schema, regex, string asserts, unit tests) before ever falling back to an LLM judge; shipping a demo with zero automated evals is the #1 reason AI take-homes get rejected."

Evaluation is the defining differentiator in modern AI engineering. Teams reject candidates who demonstrate complex agent frameworks but cannot prove their systems work reliably.

# 📐 pass@k vs pass^k: Production Reliability

Reliability Math
$$\text{pass@}k = 1 - \frac{\binom{n - c}{k}}{\binom{n}{k}}, \quad \text{vs} \quad \text{pass}^k = \left(\frac{c}{n}\right)^k$$
🗣️ Spoken Reading: pass at k measures probability of at least one success in k attempts, while pass to the power of k measures probability that all k independent attempts succeed.
SymbolMeaning & Units
nTotal generated samples per prompt (e.g., n = 20)
cNumber of correct samples passing verification
kTarget sample budget (e.g., k = 1 or k = 5)
🎯 Practical System Takeaway: pass@k flatters models (if 1 of 10 attempts passes, pass@10 is high, fine for coding assistants with human review). But for autonomous production workflows, pass^k measures reliability: if a model is 90% accurate on individual steps, a 5-step agent has pass^5 = 0.9^5 = 59% reliability!

# ⚖️ LLM-as-a-Judge & Alignment Verification

Judge Quality

Before deploying an LLM judge, you must measure judge-vs-human agreement (Cohen's Kappa). Without human validation, your judge is merely grading with its own baked-in biases.

LLM-as-a-Judge BiasMechanismEngineering Mitigation
Position BiasJudges favor whichever candidate answer is presented first in pairwise comparisons.Run pairwise evaluation twice, swapping candidate order (A/B and B/A). Discard ties.
Verbosity BiasJudges consistently score longer, wordier responses higher regardless of content.Instruct the judge to penalize fluff; enforce strict word budgets in candidate prompts.
Self-Preference BiasA judge model (e.g. GPT-4o) naturally favors outputs generated by GPT-4o over Claude/Llama.Use cross-model jury panels (e.g. average Claude 3.5 Sonnet + GPT-4o + Gemini 1.5 Pro).

# 📉 Drift Detection (PSI) & Production MLOps

Drift Math
$$\text{PSI} = \sum \left(P_i - Q_i\right) \times \ln\left(\frac{P_i}{Q_i}\right)$$
🗣️ Spoken Reading: Population Stability Index equals sum of actual minus expected percentage multiplied by natural log of actual over expected.
SymbolMeaning & Units
P_iActual production inference distribution in bin i
Q_iBaseline training / reference validation distribution in bin i
PSI < 0.1Negligible shift; model is stable
PSI > 0.2Significant distribution drift! Model must be retrained
🎯 Practical System Takeaway: When stakeholders complain 'the model got worse,' 90% of the time the model is unchanged—input distributions drifted (covariate drift). Compute PSI on embedding distances and token lengths to diagnose immediately.

# 🛠️ Production Eval Harness Implementation

Harness Code
📄 Production Evaluation Harness with Deterministic Graderspython
import re
import json

class ProductionEvalHarness:
    def __init__(self, golden_dataset):
        self.dataset = golden_dataset # List of dicts with query, expected_answer, expected_keys

    def evaluate_response(self, response_text, item):
        scores = {}
        
        # 1. Deterministic JSON validity & schema check
        try:
            parsed = json.loads(response_text)
            scores["valid_json"] = 1.0
            
            # Check mandatory keys
            missing_keys = [k for k in item.get("expected_keys", []) if k not in parsed]
            scores["schema_compliance"] = 1.0 if not missing_keys else 0.0
        except json.JSONDecodeError:
            scores["valid_json"] = 0.0
            scores["schema_compliance"] = 0.0
            
        # 2. Deterministic Regex Ground Truth Assertion
        if "expected_regex" in item:
            match = re.search(item["expected_regex"], response_text, re.IGNORECASE)
            scores["regex_match"] = 1.0 if match else 0.0
            
        return scores

By building an automated 4-tier evaluation pipeline: (1) Deterministic unit graders for syntax/schema, (2) Component metrics (Recall@k, nDCG) for retrieval, (3) Model-graded faithfulness on a curated golden set verified against human agreement, and (4) Online latency, guardrail error rates, and user engagement monitoring.

What is the difference between pass@k and pass^k?
MediumMetricsOpenAIScale AI
pass@k is the probability that AT LEAST ONE sample out of k independent attempts succeeds (good for human-in-the-loop assistants). pass^k is the probability that ALL k steps succeed consecutively (vital for autonomous multi-step agents where failure cascades).

Why might a model do worse with retrieved context than with none?
MediumRAGAnthropicPalantir
Due to context rot, distraction from irrelevant or noisy chunks, contradictory documents in the retrieval set, or the 'Lost in the Middle' effect where relevant information buried in the middle of long contexts is ignored.

What are the 3 pillars of the RAG Triad?
EasyRAGPalantirApple
Context Relevance (is retrieved context relevant to the user query?), Groundedness / Faithfulness (is the answer strictly supported by context without hallucination?), and Answer Relevance (does the answer address the question asked?).
Rate Recall:
Before you trust an LLM-as-a-judge, what must you measure?
MediumJudgesScale AIMeta
You must measure inter-annotator agreement (Cohen's Kappa) between the LLM judge's scores and human expert labels on a sampled test set. A judge with low human correlation will silently drift and game evals.
Rate Recall:
Name 3 biases in LLM-as-a-Judge scoring and their fixes.
MediumJudgesGoogleAnthropic
Position Bias (favors choice A over B -> swap order and average), Verbosity Bias (favors longer answers -> penalize token length or enforce word limits), Self-Preference Bias (favors own model family -> use multi-model juries).
Rate Recall:
A stakeholder says 'the model got worse.' You have no eval set. What do you do first?
HardDebuggingPalantirOpenAI
First, freeze production logs and pull the latest 50 user queries and responses. Compare their embedding and token length distribution against historical data to check for covariate input drift. Then construct an emergency golden set from those queries to establish a reproducible baseline.
Rate Recall:
Explain the difference between Covariate Drift, Prior Probability Drift, and Concept Drift.
MediumMLOpsAmazonUber
Covariate Drift: Input distribution P(X) changes while P(Y|X) remains fixed. Prior Probability Drift: Target label distribution P(Y) changes. Concept Drift: Relationship between input and output P(Y|X) changes (e.g. meaning of fraud changes).

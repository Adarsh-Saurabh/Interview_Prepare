# ⚡ 15-Min Sprint: Linear Algebra & SVD

Linear Algebra
🗣️ 15-SECOND INTERVIEW ANSWER

"Singular Value Decomposition (SVD) states that any real matrix A decomposes into A = U Sigma V^T: geometrically, any linear mapping represents an orthonormal rotation (V^T), an axis-aligned scaling along singular values (Sigma), and a final rotation (U)."

Mathematics in Applied Scientist and AI roles is not abstract theorem-proving; it tests geometric intuition, optimization guarantees, and information-theoretic proofs.

🔍 SVD Geometric Decomposition: Rotate -> Scale -> Rotate
$$A = U \Sigma V^T = \sum_{i=1}^r \sigma_i u_i v_i^T$$
🗣️ Spoken Reading: Matrix A factors into orthogonal matrix U times diagonal matrix Sigma times orthogonal matrix V transpose.
SymbolMeaning & Units
ULeft singular vectors (eigenvectors of A A^T, size M x M)
SigmaSingular values in descending order sigma_1 >= sigma_2 >= ... >= 0 (size M x N)
V^TRight singular vectors (eigenvectors of A^T A, size N x N)
rRank of matrix A (number of non-zero singular values)
🎯 Practical System Takeaway: Eckart-Young-Mirsky Theorem: The optimal rank-k approximation of matrix A that minimizes Frobenius norm error is obtained by truncating SVD to the top k singular values. This forms the mathematical backbone of PCA, Latent Semantic Analysis, and LoRA!

# 🎲 Bayes' Theorem & Base-Rate Fallacy

Probability
$$P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)} = \frac{P(B \mid A) P(A)}{P(B \mid A) P(A) + P(B \mid \neg A) P(\neg A)}$$
🗣️ Spoken Reading: Posterior probability equals likelihood times prior divided by marginal evidence.
SymbolMeaning & Units
P(A | B)Posterior probability (updated belief after seeing evidence B)
P(B | A)Likelihood of seeing evidence B given condition A
P(A)Prior probability of condition A before seeing evidence
P(B)Total marginal probability of evidence B
🎯 Practical System Takeaway: Crucial in interview questions regarding rare events (fraud detection, medical diagnosis). When the prior P(A) is very small (0.1%), even a 99% accurate test yields a posterior under 10%!
📐 WORKED PROBLEM

Base-Rate Fallacy: Disease Diagnosis with 99% Test Accuracy and 0.1% Prevalence

Step 1 Identify Priors and Likelihoods
Prevalence $P(D) = 0.001$, so $P(\neg D) = 0.999$. Test sensitivity (True Positive Rate) $P(+ \mid D) = 0.99$. False Positive Rate $P(+ \mid \neg D) = 1 - 0.99 = 0.01$.
Step 2 Apply Total Probability Law for Marginal P(+)
$$P(+) = P(+ \mid D) P(D) + P(+ \mid \neg D) P(\neg D) = (0.99)(0.001) + (0.01)(0.999) = 0.00099 + 0.00999 = 0.01098$$
Step 3 Calculate Posterior P(D | +)
$$P(D \mid +) = \frac{(0.99)(0.001)}{0.01098} = \frac{0.00099}{0.01098} \approx 0.09016 \approx 9.02\%$$
👁️ Click to Reveal Final Verification & Answer
Even though the test is 99% accurate, an individual testing positive has only a ~9% chance of actually having the disease! 91% of positive results are false positives because healthy people vastly outnumber sick people.

# ∑ Information Theory: Forward vs Reverse KL

Info Theory
KL DirectionFormulaBehavior on Bimodal DistributionProduction Adoption
Forward KL (Zero-Avoiding)$D_{\text{KL}}(P \parallel Q) = \int P \log \frac{P}{Q}$Mass-Covering: Q stretches to cover all regions where P > 0, even placing mass in empty valleys.Maximum Likelihood training in standard language models.
Reverse KL (Zero-Forcing)$D_{\text{KL}}(Q \parallel P) = \int Q \log \frac{Q}{P}$Mode-Seeking: Q locks onto a single peak of P where Q can match P closely, ignoring other modes.Variational Inference (VAE), RLHF / DPO policy alignment.

# 🔢 Numerical Stability & Log-Sum-Exp

Math Code
📄 Numerically Stable Softmax Implementationpython
import numpy as np

def stable_softmax(logits):
    # Subtracting the maximum prevents overflow into inf in exp()!
    # Mathematically identical because exp(x - c) / sum(exp(x - c)) == exp(x) / sum(exp(x))
    shifted_logits = logits - np.max(logits, axis=-1, keepdims=True)
    exp_logits = np.exp(shifted_logits)
    return exp_logits / np.sum(exp_logits, axis=-1, keepdims=True)

What does SVD do geometrically, and how does it relate to PCA?
MediumSVDPCAGoogleDeepMind
SVD decomposes any real matrix into a rotation (V^T), scaling (Sigma), and second rotation (U). PCA performs an eigendecomposition on the centered covariance matrix (X^T X / (N-1)), where right singular vectors V of X correspond exactly to the principal components (eigenvectors).

Prove that MAP estimation with a Gaussian prior is equivalent to L2-regularized MLE.
HardRegularizationOpenAIMeta
Under Bayes' rule: log P(theta | D) = log P(D | theta) + log P(theta). For a Gaussian prior P(theta) ~ N(0, sigma^2), log P(theta) = - (1 / (2*sigma^2)) * ||theta||_2^2 + const. Maximizing the posterior is thus mathematically identical to maximizing log-likelihood minus lambda * ||theta||_2^2.

Why is Forward KL mass-covering while Reverse KL is mode-seeking?
HardInfo TheoryDeepMindAnthropic
In Forward KL (P || Q), if P(x) > 0 but Q(x) -> 0, the integrand P log(P/Q) diverges to infinity, forcing Q to cover all modes of P. In Reverse KL (Q || P), if P(x) = 0 and Q(x) > 0, Q log(Q/P) explodes, forcing Q to remain zero anywhere P is zero (locking onto one mode).
Rate Recall:
Why must softmax subtract the max element before exponentiating?
EasyNumericalApple AINvidia
In standard 32-bit floating point, exp(x) overflows to +inf when x > 88.7. Subtracting max(x) ensures the maximum exponent evaluated is exp(0) = 1.0, eliminating float overflow while preserving exact probability proportions.

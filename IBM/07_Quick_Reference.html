3. 10 Rapid-Fire Pre-Interview Q&As

# Rapid-Fire Question Key Systems Answer
1 Big-Endian vs. Little-Endian? Big-Endian stores MSB at lowest address (s390x). Little-Endian stores LSB at lowest address (ppc64le, x86_64).
2 Why Telum Virtual L3/L4? Saves die area by dynamically interconnecting private 32MB L2s of neighboring cores over 320 GB/s ring rather than dedicated SRAM.
3 What happens on fork()? Duplicates page table entries marked read-only. Physical pages duplicated on write fault (Copy-on-Write / do_wp_page).
4 What is False Sharing? Cores writing independent variables on same 64-byte cache line causing cache line bouncing. Fix with alignas(64).
5 Spinlock in ISR? Must disable local interrupts (spin_lock_irqsave) to prevent ISR on same core re-entering lock and deadlocking.
6 What is OpenBMC? Linux distribution running on out-of-band ASPEED SoC, managing hardware sensors/power without consuming host CPU cycles.
7 Power10 Memory Inception? Uses optical OMI interconnect to share memory across server drawers as cache-coherent NUMA nodes with sub-100ns latency.
8 Process vs. Thread in Linux? Both are task_struct; threads share address space (CLONE_VM) and file descriptors (CLONE_FILES).
9 Condition Variable vs. Busy Loop? Busy loop wastes 100% CPU core cycles. Condition variable sleeps thread in kernel queue until woken via notify_one().
10 PathMapper L3 Cache Fit? Contiguous 1D array + 64-bit obstacle bitmasks packed 100M nodes into 12MB RAM, residing entirely in CPU L3 cache.
